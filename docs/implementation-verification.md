# 게임 개선 구현 검증

검증일: 2026-09-10\
검증 대상: 검증 시점의 현재 작업 트리\
검증 서버: `http://127.0.0.1:3100`, `DATA_BACKEND=local`\
브라우저: Playwright Chromium, 1024×768 태블릿 화면

## 결과

기능 차단 문제 없이 세 게임의 게스트 흐름을 완료했다. 학생 기록 데이터 API는 mock으로 격리했으며 Apps Script, 실제 학급 시트, 실제 학생 데이터에는 접근하거나 쓰지 않았다.

미션 1의 재선택 기록은 첫 선택과 최종 선택이 다르고 `reconsiderations: 1`인 결과로 저장됐다. 미션 2 일반 완주는 `correct: 3`, `answered: 4`, `activeRunSec: 37`로 저장됐고, 검증을 위해 해설에서 기다린 시간이 포함된 전체 활동 시간과 달린 시간이 분리됐다. 미션 3은 작성한 33자 원문과 선택 장면·감정·현재 콘텐츠 버전이 그대로 저장됐다.

버전 호환은 현재 표준인 `details.contentVersion`과 `details.schemaVersion`을 우선 읽고, 기존 최상위 버전 필드도 fallback으로 읽는 13개 assertion으로 확인했다. Apps Script 표시 계산도 같은 조건에서 미션 1의 첫 선택 `2/3`, 미션 3 글 원문, 현재 완료 수 3, 이전 완료 수 0을 반환했다.

## 코드 검토

학생 화면에는 질문 생성, 예상, 자기 점검 단계를 추가하지 않았고 러너는 읽은 내용을 확인하는 쉬운 객관식 네 문제로 구성됐다. 확인된 사실인 장대공원의 태현이와 연우의 갈등과 화해, 범암마을의 큰 해일, 복사골의 고문서만 사용한다. 갈등 이유, 원작 대사, 고문서 내용, 보물의 정체는 사실처럼 만들지 않았다. 선택 모험의 말은 원작 인용이 아닌 학생의 대화 연습으로 읽히며, 한 장면에서 둘 이상의 존중하는 선택을 인정한다.

`태현이와`, `태현이가`, `태현이의`를 포함한 이름 조사를 확인했다. 개인 이름 제목은 받침에 따라 `김태현이의`, `조연우의`, `루미의`로 만들어지고 게스트에는 개인 이름을 붙이지 않는다.

별도 코드 리뷰의 최종 결과도 승인으로 종료됐으며 남은 기능 차단 항목은 없었다.

## 미검증 및 보류 범위

- Playwright가 다른 탭의 `document.hidden`을 `false`로 유지하는 환경이어서 실제 OS 탭 휴면은 재현하지 못했다. `visibilitychange`와 `document.hidden=true`를 브라우저에서 발생시킨 검증에서는 4초 동안 남은 시간이 변하지 않았다. 실제 태블릿 브라우저의 앱 전환·화면 잠금은 수업 기기에서 추가 확인해야 한다.
- 실제 태블릿 하드웨어의 터치 지연, 화면 회전, 소프트 키보드 크기는 자동화 환경에서 확인하지 않았다. 1024×768 화면에서 버튼과 본문이 읽히고 스크롤 가능한 것은 확인했다.
- 실제 원문이 제공되지 않았으므로 갈등의 구체적 이유와 대사, 고문서 내용, 보물의 정체를 다루는 최종 사실 문항은 검증 범위가 아니다.
- 신규 이미지 생성과 연결은 사용자 요청에 따라 보류됐다. 현재 검증은 기존 루미 스프라이트와 러너 배경, 이미지 없는 신규 이야기 장면을 대상으로 했다.
- 실제 Apps Script 배포와 학급 시트 연결은 의도적으로 검증하지 않았다.
